这篇教程帮你快速上手 NoCodeFlow，从首次启动到核心功能，一步步来。

## 首次启动

第一次打开 NoCodeFlow 会进入欢迎引导页：

:::note{type="info"}
1. 点击「开始配置」进入下一步（也可以「跳过引导」直接进主界面）
2. 选择主题——浅色、深色或跟随系统，之后随时可以在设置里改
3. 配置 AI 服务——填入你的 API Key，给配置起个名字。暂时没有也可以跳过
4. 点击「完成」进入主界面
:::

## 认识界面

NoCodeFlow 的界面分三个主要区域，如下所示：

```ascii
┌──────────┬──────────────────────────┬─────────────┐
│          │                          │             │
│  侧边栏   │      主要工作区域          │   AI 聊天    │
│          │                          │    面板      │
│  · 任务中心│   （文件树 / 编辑器 /     │             │
│  · 工作空间│    文档查看 / 设置）       │   跟 AI 对话  │
│  · 知识库  │                          │             │
│  · 设置   │                          │             │
└──────────┴──────────────────────────┴─────────────┘
```

**侧边栏**（左侧）有四个入口：

| 图标 | 名称 | 用途 |
|------|------|------|
| 🏠 | 任务中心 | 首页，查看任务概览 |
| 📁 | 工作空间 | 打开文件夹、编辑文件、与 AI 协作 |
| 📚 | 知识库 | 管理知识资料（即将上线） |
| ⚙️ | 设置 | 个性化配置 |

*小提示：侧边栏可以折叠节省空间，鼠标悬停图标会显示名称哦。*

## 打开工作文件夹

1. 点击侧边栏的「工作空间」
2. 点击「打开文件夹」按钮
3. 在系统对话框中选择你的项目文件夹

打开后：
- **左侧**：文件树，像文件管理器一样浏览文件
- **中间**：编辑区，双击文件即可打开编辑
- **右侧**：AI 聊天面板（默认隐藏，点工具栏的对话按钮打开）

:::note{type="success"}
NoCodeFlow 会记住你最近打开过的文件夹，下次可以直接快速打开，非常方便！
:::

## 跟 AI 对话

这是最核心的功能——用自然语言告诉 AI 你想做什么。

### 怎么聊

在工作空间工具栏点对话按钮打开聊天面板，在底部输入框打字描述需求，按回车发送，AI 会实时流式回复。

### 可以这样说

> "帮我在 src 文件夹下创建一个 hello.ts 文件，写一个打招呼的函数"

> "帮我看看 index.ts 里的代码有什么问题"

> "把这篇文章的 PDF 导入进来，帮我总结一下"

### 其他操作

- 点历史按钮可以查看历史消息
- 点 ⏹ 可以中断正在回答的 AI

## 编辑和管理文件

### 文件树

- **双击文件**：在编辑器中打开
- **右键文件**：重命名、删除等操作
- **点击文件夹**：展开/折叠

### 工具栏功能

| 按钮 | 功能 |
|------|------|
| 返回 | 退回到任务中心 |
| 打开文件夹 | 选择新文件夹 |
| 保存 | 保存当前文件 |
| AI 助手 | 开关聊天面板 |
| ⏺ 时间线 | 开关操作时间线 |
| 快照 | 开关快照面板 |

## 安全确认机制

AI 不会"乱来"。当它要执行操作时，屏幕中央会弹确认框，显示它想做什么、涉及哪些文件。

你可以：
- ✅ **允许**：同意这次操作
- ❌ **拒绝**：不同意，AI 跳过这步
- **不再询问**：对同类操作自动允许（谨慎使用）

只有你明确同意的操作，AI 才会执行。

## 快照与回滚：随时反悔

这是让 AI 放心干活的"后悔药"。

:::note{type="warning"}
**自动快照**：每次 AI 修改文件前，NoCodeFlow 自动保存当前状态，不需要你做任何事！
如果发生问题，打开快照面板，找到之前的记录一键回滚。
:::

## 常见问题

**启动后提示找不到 AI 服务？**
确保在「设置 → Agent 配置」中添加了至少一个配置，并填入正确的密钥。

**AI 回答很慢？**
取决于 AI 服务和网络状况，可以切换更快的模型或检查网络。

**AI 改了不想要的文件？**
用快照功能一键恢复即可。
