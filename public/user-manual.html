产品简介

NoCodeFlow 是一个桌面应用。你在输入框里用日常语言描述想做的事，AI 会帮你写代码、改文件、整理文档。 不需要会编程，只要把需求说清楚就行。

它把代码编辑器、文档管理、知识库搜索和 AI 对话集成在同一个界面里，省去了在多个工具之间来回切换的麻烦。

它能做什么

  • 用说话的方式完成工作 — 在输入框里写「帮我做一个计算器」，AI 会自己写好代码
  • 接入多种 AI 服务 — 支持小米 MiMoCode、Anthropic Claude、OpenAI 等，按需切换
  • 管理你的文档资料 — 把 PDF、Word、Markdown 导入知识库，可以用关键词搜索，也可以向 AI 提问让它从文档里找答案
  • 改文件前先问你 — AI 要修改代码或执行命令时，会弹窗让你确认，并且显示改了哪些内容
  • 随时回到之前的状态 — 系统会自动保存项目快照，改坏了可以一键恢复
  • AI 自动了解你的项目 — 对话时 AI 会自动读取当前代码、文档和知识库内容，不需要你手动复制粘贴

如何提交任务

输入任务描述

快捷标签

AI Agent 对话

AgentAI 助手。你用自然语言告诉它要做什么，它会帮你写代码、改文件、执行命令，遇到关键操作会先问你 是 NoCodeFlow 的核心交互方式。在工作空间中点击「Agent」按钮打开对话面板。

对话界面组成

  • 状态栏 — 显示 Agent 当前状态（就绪/运行中/错误/完成）
  • 消息区域 — 显示你和 AI 的对话内容，支持 Markdown 渲染
  • 操作记录 — 显示 Agent 执行过的每一步操作（读文件、写代码、运行命令等）
  • 上下文指示 — 显示 AI 当前参考了哪些文件和知识库内容
  • 输入框 — 输入消息，Enter 发送

如何与 Agent 对话

打开 Agent 面板

在工作空间中点击工具栏的「Agent」按钮，右侧面板展开。

输入你的需求

在底部输入框中用自然语言描述，例如「帮我在 index.ts 中添加一个 greeting 函数」。

查看执行过程

Agent 会显示思考状态，然后逐步执行操作，右侧操作记录面板会记下每一步。

确认权限请求

当 Agent 需要写入文件或执行命令时，会弹出权限确认对话框（见权限管理）。

⚠
Agent 执行文件写入操作前会弹出确认对话框，显示变更差异（Diff）。请仔细检查后再点击「允许」。

消息历史

点击对话区域右下角的 ☰ 按钮，可以查看历史消息列表并快速跳转到指定位置。

知识库

知识库用于集中管理你的文档资料。导入后可以搜索关键词，也可以用自然语言向 AI 提问，让它从文档中找答案。

导入文档

支持以下格式：

格式扩展名说明
PDF.pdf自动提取文本、目录结构
Word.docx支持富文本和图片描述
Markdown.md完整支持 GFM 语法

你可以直接将文件拖拽到知识库页面，系统会自动弹出导入对话框。

文档搜索

切换到「搜索」标签页，输入关键词即可在所有已导入的文档中进行全文检索。搜索结果按相关度排序，支持结果高亮。

跨文档问答

切换到「问答」标签页，你可以：

  • 输入自然语言问题，AI 基于知识库中的文档生成回答
  • 点击 @ 按钮引用特定文档，限定问答范围
  • 每条回答自动标注引用来源（文档名 + 页码）

快照与回滚

快照功能让你随时保存项目状态，在需要时一键恢复。这对于 AI 修改代码后的安全回退特别有用。

打开快照面板

在工作空间工具栏点击「快照」按钮，右侧面板展开，显示快照历史列表。

快照面板功能

  • 操作组 — Agent 执行的多步操作会被自动分组，方便整组回滚
  • 单文件快照 — 每次文件修改都会记录
  • 查看差异 — 点击快照项查看文件变更的 Diff 视图
  • 恢复 — 选择一个快照点，将文件恢复到该状态
ℹ
快照系统优先使用 Git 仓库。如果项目不是 Git 仓库，会使用 .nocodeflow 目录存储快照。

上下文引擎

上下文引擎系统自动收集你当前的代码、文档、知识库等内容，一起发给 AI，这样 AI 回答时能参考你的实际项目情况 是让 AI 更好理解你项目的幕后功臣。它在每次对话时自动运行。

上下文来源

AI 对话时会参考以下几类信息：

来源说明
代码你当前打开的文件和项目结构
文档知识库中与问题相关的文档片段
知识知识库中语义相近的内容
偏好你在设置中配置的代码风格、写作习惯
记忆从之前的对话中积累的项目信息

上下文面板

在 Agent 面板底部可以看到当前注入了哪些信息，以及占用了多少 AI 处理容量（以 Token 计量，Token 是 AI 处理文本的基本单位，大致 1 个中文字 ≈ 1~2 个 Token）：

  • 容量环 — 显示已用容量的百分比，超过 90% 会变红
  • 来源开关 — 点击某个来源标签可以临时关闭它，减少注入量
  • 置顶/排除 — 对某条内容置顶（每次对话都带入）或排除（不带入）
  • 撤销 — 支持 5 步撤销，误操作可以恢复

权限管理

AI 在操作你的文件或执行命令之前，必须经过你确认。所有修改都会显示具体内容，让你决定是否放行。

权限确认对话框

当 Agent 需要执行敏感操作时，会弹出权限确认对话框：

权限确认
🛡
权限确认

📄 src/index.ts

Enter 允许 · Esc 拒绝

风险等级

等级操作类型行为
✅ 自动允许 读取文件、搜索 无需确认，自动执行
⚠ 需要确认 写入文件、编辑 弹窗确认，显示变更差异
🚫 高危操作 执行命令（Bash） 弹窗确认，不可设置自动跳过
⚠
文件写入操作会显示 Diff 视图，让你清楚看到 AI 要修改的内容。文档文件则显示内容预览。

批量操作

当有多个权限请求排队时，你可以：

  • 逐一审核并允许/拒绝
  • 点击「全部接受」按钮一次性批准所有待处理请求
  • 勾选「本次会话不再询问此操作」减少重复确认

命令面板

命令面板是 NoCodeFlow 的快速操作入口，类似 VS Code 的 Command Palette命令面板：通过键盘快速搜索和执行应用内各种操作的浮动窗口。

打开方式

按 Ctrl+K（Mac 上为 Cmd+K），或点击顶部搜索栏。

支持的操作

  • 页面导航 — 快速跳转到任务中心、工作空间、知识库等页面
  • 文件操作 — 搜索并打开项目中的文件
  • Agent 操作 — 发送消息给 AI
  • 设置 — 直接跳转到特定设置项
  • 快捷键速查 — 输入 ? 查看所有可用快捷键

搜索技巧

命令面板支持三种模糊匹配模式：

方式示例说明
直接包含Agent匹配标签中包含「Agent」的命令
首字母匹配fs匹配按空格/连字符拆分后的首字母，如 "file search"
逐字符匹配agst按顺序匹配标签中的字符，如 "Agent Status"
ℹ
模糊匹配对英文标签效果最佳。搜索中文命令建议直接输入关键词（如「知识」「设置」）进行包含匹配。

支持键盘导航：↑↓ 选择，Enter 执行，Esc 关闭。

适配器与 Skill

点击侧边栏的「🤖」图标进入 Agent & Skill 管理页面。

适配器管理

NoCodeFlow 通过「适配器」连接不同的 AI 服务。你可以根据自己的需要选择：

适配器能力适合场景
MiMoCode（推荐） 完整 支持小米 MiMo 系列模型，也能接入 DeepSeek 等第三方服务。AI 可以边回答边操作文件
Claude Code 完整 需要 Anthropic Claude 模型的高级能力时使用，需要先安装 Claude CLI 工具
Claude API 基础 直接调用 Anthropic API 进行文字对话，不支持文件操作
OpenAI 兼容 实验性 接入任何兼容 OpenAI 接口的服务

Skill 管理

Skill 是给 Agent 安装的「插件」，能让它学会新本领。在「Skill 管理」标签页中你可以：

  • 浏览和安装社区提供的 Skill
  • 启用或禁用已安装的 Skill
  • 控制每个 Skill 可以访问哪些资源
  • 查看 Skill 的运行记录

通用设置

点击侧边栏的「⚙ 设置」图标，进入设置页面。默认显示「通用」标签。

主题

三种主题模式可选：

  • 浅色 — 适合明亮环境
  • 深色 — 适合暗光环境，减少视觉疲劳
  • 跟随系统 — 自动匹配操作系统的深浅色设置

字体大小

通过滑块调节编辑器字体大小，范围 12px ~ 24px。拖动时实时显示数值气泡。

编辑器主题

Monaco Editor 的配色方案：浅色（vs）、深色（vs-dark）、高对比（hc-black）。

侧边栏位置

可选择将导航侧边栏放在左侧或右侧。

实验性功能

  • 上下文注入指示器 — 在对话输入框旁显示上下文摘要徽章

响应式布局

NoCodeFlow 会根据窗口宽度自动调整布局：

窗口宽度行为
≥ 1200px完整布局：侧边栏 + 编辑器 + 右侧面板全部显示

你可以手动展开已折叠的侧边栏，系统会尊重你的选择，不会在窗口大小变化时强制重新折叠。

Agent 配置

在「Agent 配置」标签页中管理 AI 服务方案。你可以配置多个方案并快速切换。

添加方案

选择 Agent 引擎

选择 MiMoCode（推荐）或 Claude Code、Claude API、OpenAI 兼容。

配置提供商

MiMoCode 支持小米官方（推荐，原生模型）和第三方自定义（DeepSeek、OpenAI 等）两种模式。

填写 API Key

输入对应的 API 密钥。密钥会加密存储在本地。

高级设置（可选）

配置 Agent 运行模式、安全拦截、高精度模式、Temperature 等参数。

小米官方模型

模型说明
mimo-v2.5-pro推荐，多模态支持，能力最强
mimo-v2.5标准版，性价比高

高级设置说明

选项说明
Agent 运行模式 执行模式 AI 可以直接修改你的代码文件； 只读规划 AI 只分析和出方案，不动任何文件。适合先让 AI 想清楚再动手
文件安全拦截 (HITL) 开启后，写入文件前会弹窗确认
高精度模式 AI 会同时生成多个回答，挑最好的一个返回。效果更好，但消耗的额度约为普通模式的 4~5 倍
Temperature 控制 AI 回答的「创意程度」。调低（接近 0）回答更严谨、重复；调高（接近 2）回答更多样、但可能不稳定。一般保持默认值 1 即可

权限设置

在「权限管理」标签页中配置 Agent 的操作权限规则。

  • 查看当前的权限规则列表
  • 添加自定义允许/拒绝规则
  • 管理路径白名单（Agent 可访问的目录）
  • 查看被拦截的操作历史

记忆管理

记忆系统AI 会记住你之前对话中提到的项目信息和偏好，下次对话时自动参考 让 AI 能够记住你的项目特点和使用偏好。

记忆类型

类型说明示例
项目知识项目的技术栈、目录结构、约定「本项目使用 React + TypeScript」
用户偏好你的代码风格、输出格式偏好「使用 4 空格缩进」
会话记忆对话中积累的上下文「上次讨论了登录功能的设计」
Agent 学习成功/失败模式「用户的项目不支持 ESM」

在设置页面可以查看、搜索、编辑和删除记忆条目。

常见问题

Agent 提示「未连接」怎么办？ ▶

请检查以下几点：

  1. 确认已在「设置 > Agent 配置」中添加了至少一个方案并设为激活状态
  2. 确认 API Key 已正确填写（密钥会显示为 sk-***xxxx 格式）
  3. 确认网络连接正常（特别是使用第三方 API 时）
  4. 如果使用 Claude Code 引擎，确认已全局安装 CLI：npm install -g @anthropic-ai/claude-code
如何切换不同的 AI 模型？ ▶

在「设置 > Agent 配置」中，点击方案卡片上的「激活」按钮即可切换。切换后需要重启 Agent 生效。

你可以为不同场景配置多个方案，例如日常使用 MiMoCode，需要精确输出时切换到 Claude API。

快照和 Git 有什么区别？ ▶

快照系统是 NoCodeFlow 内置的备份机制，特点：

  • 自动在 Agent 操作前创建快照
  • 无需手动 commit
  • 支持非 Git 项目（使用 .nocodeflow 目录）
  • 操作组级别的整组回滚

如果你的项目已有 Git，快照系统会优先使用 Git 来存储。

知识库支持多大的文件？ ▶

导入时系统会自动将文档分段存储（Chunking），大文件会被拆分为多个段落以便检索。导入过程中会显示进度条，你可以随时了解处理状态。

支持的格式包括 PDF、Word（.docx）、Markdown 和纯文本。具体大小限制取决于系统可用内存。

Agent 写入的文件可以撤销吗？ ▶

可以。有三种方式：

  1. 快照回滚 — 打开快照面板，选择操作前的快照点恢复
  2. 权限拒绝 — 在权限确认弹窗中点击「拒绝」
  3. 手动撤销 — 在编辑器中使用 Ctrl+Z
上下文引擎占用太多 Token 怎么办？ ▶

你可以通过以下方式减少 AI 的处理负担：

  • 在上下文面板中排除不需要的来源（比如暂时关闭「记忆」）
  • 置顶真正重要的内容，让 AI 优先关注
  • 系统会自动压缩和截断过长的内容，一般不需要手动干预
